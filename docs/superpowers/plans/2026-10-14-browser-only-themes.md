# EchoMark v0.4.1 实施计划

**目标：** 只保留浏览器识别，缩短英语位置指令，改善两套新主题；保留原版样式和历史版本。

**实现方式：** 沿用现有独立源码目录，在 `versions/v0.4.1/` 修改。原版 `styles.css` 保持不变，主题改动仅进入 `themes.css`。使用当前干净的独立发布 checkout。

## 任务

- [x] 删除新版本中的本机模型、Worker 和采样工作线程，移除加载入口、脚本与缓存依赖。
- [x] 移除本机识别探测等待，直接建立浏览器识别会话；保留静音恢复、失败退避、手动停止和过期回调隔离。
- [x] 增加简短英语定位与数字距离写法，保留旧指令兼容；帮助改为 `go to start / skip 20 / back 20`。
- [x] 仅在 Material You / MiuiX 下调整色彩层级、卡片分组、选中状态、字体、边框、触控间距和响应式布局。
- [x] 根据用户补充要求，共用两套主题的尺寸与字号；英语推荐命令改为 go to、skip、back，旧写法兼容。
- [x] 更新版本号、产品说明、设计依据、第三方说明、根目录说明和 Pages 部署路径。
- [x] 检查语法、剩余依赖和原版样式一致性；按开发者要求不新增或运行测试。

发布流程：提交、创建 `v0.4.1` 标签、推送、发布独立 Release 并确认 Pages 部署。

独立审查补充：简短数字距离必须按字符计数移动；Service Worker 必须预缓存页面请求的确切版本参数 URL。两处已修正并重新审查。

## 边界与风险

浏览器内置识别是否可用由浏览器和系统服务决定；网页保留重试和复制链接提示。用户已明确取消云端识别和模型方案。

计划由当前会话直接执行。发布授权沿用用户既定版本流程；所有任务合并为一个可追溯的版本提交。
