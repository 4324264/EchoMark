# EchoMark v0.2.7

**尽量保留原文件的阅读观感，并按实际标记速度估算剩余时间。**

## 本版本改动

- PDF 页面加入高分辨率原页底图，显示原有文字、表格线、图形和带外观的批注；透明文字层负责语音索引、选择和高亮。
- 支持 XLSX、XLS、XLSM、XLSB、ODS 和 CSV。保留工作表、单元格网格、合并区域、常见边框/颜色/字体对齐，并展示可读取的文字批注。单元格框线仅用于显示，不参与朗读匹配。
- 顶栏头像与右侧状态之间增加间距。
- 剩余时间旁新增刷新按钮。首次仍按默认速度估算；监听推进足够文字后，点击按钮按累计标记字符和监听时间重算，并将估算速度保存在当前浏览器、对应文档下。之后会沿用该速度，直到再次刷新。

## 说明和限制

PDF 底图采用本地渲染，不会上传文档；扫描件可以显示原页图像，但若没有文字层则无法语音匹配。PDF 的批注仅能显示 PDF 文件中可渲染的批注外观，交互式表单和复杂对象不保证完整。Excel 使用 SheetJS Community Edition 读取；单元格网格与基础格式由网页补充绘制，原文件的高级格式、条件格式、图表、图片、数据验证和线程式评论可能无法还原。单个工作簿最多处理 5 万格。

PDF 和 Excel 首次导入需要联网载入对应阅读库。阅读位置、估算速度和其他偏好保存在当前浏览器，不会跨设备同步。

本仓库没有附加开源许可证。
