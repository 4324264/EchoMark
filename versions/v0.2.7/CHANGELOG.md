# EchoMark v0.2.7 — 2026-10-07

## 新增

- 支持 PDF 页面原貌底图与 Excel/ODS/CSV 工作表导入。
- 新增按监听期间的标记推进速度手动刷新剩余时间。
- 调整 GitHub 头像与右侧状态信息的间距。

## 改进

- PDF 的表格线、图形和可绘制批注作为底图呈现；阅读标记仍通过透明文字层准确定位。
- Excel 按工作表和行列展示内容，提供网格线，保留单元格合并、基础样式及可读取的文字批注；这些装饰不进入语音文字索引。进度字符统计排除表格分隔空白。
- 点击刷新后用累计监听时间与推进字符数计算速度；未点击刷新时继续沿用现有估算速度。

## 已知限制

- 扫描 PDF 没有可索引的文字层；复杂注释/表单显示受 PDF.js 限制。
- Excel 高级样式、条件格式、图片、图表及线程式评论不保证保留；工作簿上限为 15 万格。

# EchoMark v0.2.3 — 2026-10-07

- 修复浏览器静默超时或临时断开后识别服务结束、监听意外关闭的问题；在用户没有主动暂停时采用渐进退避自动重连。
- 修复语音识别将口令和目标文字分段返回时指令被当成普通朗读的问题，增加最长 8 秒的目标暂存。
- 扩展中文口令别名，允许口令前有常见语气词和标点，并让中英文口令共用一致的解析流程。
- 保留 v0.2.2 的移动端响应式布局。

# EchoMark v0.2.4 — 2026-10-07

- 监听期间保持麦克风音频流打开；静音导致 Web Speech 识别会话结束后，快速自动重启识别，直至用户手动停止。
- 自动恢复只对识别服务的自然结束使用短间隔；启动失败采用渐进退避，避免短时间内反复请求。
- 浏览器标签页重新回到前台时，检查并恢复仍由用户启用的监听。
- 手动停止会结束识别、取消重连并释放麦克风流；不可恢复的麦克风权限或设备错误会提示用户检查。

# EchoMark v0.2.5 — 2026-10-07

- 在监听面板底部增加简洁的“跳转、快进、撤回”语音指令指南，展示可照读的目标格式。
- 悬停、键盘聚焦或点击指令可查看简短用法说明；触屏设备点击展开，点击外部或按 Escape 收起。
- 更新网页标题、页脚、PWA 名称和 Service Worker 缓存版本；部署时主动检查新版缓存，减少公开页面仍显示旧版本的情况。

# EchoMark v0.2.6 — 2026-10-07

## 新增

- 顶栏新增 GitHub 头像，点击可打开 `4324264` 的 GitHub 主页。
- HTML、DOCX、PDF 导入保留常用的版面结构，Markdown 导入保留标题、列表、引用和代码格式。
- PDF 页面按从上到下、同一行从左到右的阅读顺序重建文字索引；语音匹配从当前标记处继续向后。
- 正文选择菜单在保留版式的导入文档中也可用。

## 改进

- 结构化文档显示和语音索引共用相同的字符序列，避免视觉顺序与朗读匹配顺序不一致。
- DOCX 表格保留行列阅读顺序、边框和部分单元格格式；HTML 只复制安全的常见格式样式。

## 已知限制

- 扫描 PDF 需要先进行 OCR；PDF 多栏与复杂阅读顺序按页面坐标推断，不保证完全还原原排版。
- DOCX 图片、浮动对象及复杂页面布局未导入；HTML 外部样式表不会下载。
