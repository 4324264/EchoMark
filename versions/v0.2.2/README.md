# EchoMark v0.2.2

**自然读到哪儿，就标记到哪儿；也可以说出目标位置，直接调整进度。**

此目录是一个独立网页版本。根目录中的原有网页文件保持不变。

此版本修复阅读标记后的正文漏字、模糊匹配回溯方向不一致，以及切换文档/监听会话时旧识别回调影响当前状态的问题。

页面根据浏览器视口宽度自动切换电脑、平板和手机布局，不需要登录或手动选择设备模式。阅读进度仍保存在当前浏览器本地，不会在设备之间同步。

手机布局加大了选择、按钮和表单的触控区域，优化安全区留白、长文阅读高度和识别结果换行；横屏窄屏也会采用紧凑布局。

## 本版本新增

- 语音指令：说“跳转到”并读出文中的一段文字、`第 50 个字`、`百分之 50`、`开头`或`结尾`。
- 快进指令：说“快进到”并指定位置，或说“快进 100 字”。英文识别也支持 `jump to`、`rewind to` 和 `fast forward to`。
- 撤回指令：说“撤回到”并读出当前位置之前的文字，或说“撤回 20 个字”。
- 手动操作：在正文中选中一段文字，从浮动菜单选择“跳转到这里”“撤回到这里”“快进到选区后”或“不操作”。
- 跳转定位优先匹配当前位置附近的文本，再按 100 字递增扩大搜索范围；最多搜索文档的 90%。

语音指令建议一口气说完整，例如“跳转到——这里读一段原文”。目标是原文时，读出至少两个连续文字字符可提高定位准确度。百分比位置和第几个字不需要匹配原文。

## 启动

使用 Python 3 在此目录启动本地网页服务器：

```powershell
python -m http.server 8000
```

然后打开 <http://localhost:8000>。麦克风仅在点击“开始标记抄写”后启用；语音识别可用性取决于浏览器、系统和网络。阅读进度和外观设置保存在当前浏览器。

## 支持格式与限制

支持 TXT、Markdown、HTML、DOCX、可提取文字的 PDF 和粘贴文本。PDF 首次导入时需要联网加载 Mozilla PDF.js；扫描版 PDF 需先 OCR。复杂版式和表格不会完全保留。本网页没有账户或云同步。
