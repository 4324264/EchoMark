# EchoMark v0.2.8 — 2026-10-07

## 新增与改进

- 顶栏状态点在监听期间缓慢呼吸；本机麦克风音量检测到说话声时，以约 0.6 秒的节奏脉冲闪烁。
- 重复执行“撤回到 + 相同目标文字”时，下一次从上一次命中片段之前搜索，连续回退到更早的同文位置。
- 阅读外观增加青岚、暖纸、雾紫、海盐四套预置配色，可一键应用。
- 细项调色新增阅读面板色与强调色，可自定义界面背景、阅读面板、标记颜色、正文颜色和强调色。
- 新增配色仍保存在当前浏览器；识别匹配、标记和语音分析仍在本地页面内处理。

## 说明

- 声音脉冲使用浏览器 Web Audio API 在本机分析麦克风音量，不录音、不存储、不上传声音。浏览器不支持音量分析时仍可显示监听状态呼吸动画。
- 语音识别本身仍依赖当前浏览器或设备提供的 Web Speech 服务。
