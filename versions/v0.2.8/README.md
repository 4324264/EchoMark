# EchoMark v0.2.8

**语音状态一目了然，重复撤回可以逐次向前定位，阅读外观更易定制。**

## 本版本改动

- 顶栏绿色状态点在监听时缓慢呼吸，麦克风检测到声音时跟随语音节奏短促闪烁；声音强度只在本机浏览器测量。
- 对同一段重复说“撤回到 + 目标文字”，每次都会从上一次命中位置之前继续查找，便于逐段撤回相同内容。
- 阅读外观增加青岚、暖纸、雾紫、海盐四套预置配色；可分别调节界面背景、阅读面板、标记、正文和强调色，并在当前浏览器保存。

## 说明和限制

麦克风声音强度在浏览器本地进行分析，不保存或上传音频；浏览器的语音识别服务仍由浏览器或设备提供。配色与阅读位置保存在当前浏览器，不会跨设备同步。浏览器若不支持 Web Audio 音量分析，状态点仍会以监听呼吸动画提示监听状态。

本仓库没有附加开源许可证。
