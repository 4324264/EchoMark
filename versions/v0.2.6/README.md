# EchoMark v0.2.6

**按正常阅读顺序定位：从左到右、从上到下；标记从当前位置继续向后匹配。**

v0.2.6 改进格式文档导入，并在顶栏加入 GitHub 头像入口。导入后的文字、排版结构与标记索引共用同一份有序内容模型，朗读匹配和选区手动定位使用相同的字符位置。

## 本版本改动

- HTML 导入保留常见标题、段落、列表、引用、代码块、表格、内联格式和安全的内嵌 CSS 样式；脚本、嵌入对象等活动内容不会显示。
- DOCX 导入保留段落、常见标题样式、粗体/斜体/下划线、字号与颜色、表格和单元格合并信息。
- PDF 文字按页面坐标重排：先从上到下，再按同一行从左到右。正文以页面形式显示，定位索引采用相同顺序。
- Markdown 显示标题、段落、列表、引用、行内粗斜体、行内代码和围栏代码块。
- 语音匹配仍从最后标记位置向后寻找，跳过内容时逐步扩大附近搜索范围；手动选择正文也能定位到对应字符。
- 顶栏头像默认加载 GitHub 用户 `4324264` 的公开头像，点击可打开该 GitHub 主页。

## 使用

打开 [EchoMark 公网页面](https://4324264.github.io/EchoMark/?v=0.2.6)，导入文档后点击“开始标记抄写”。PDF 首次导入需要联网加载 Mozilla PDF.js。页面会根据屏幕宽度自动适配手机和电脑。

阅读进度与外观设置保存在当前浏览器，不会自动跨设备同步。只有包含可选择文字的 PDF 能直接导入，扫描件需要先做 OCR。版式复杂的 PDF、多栏阅读顺序和 DOCX 浮动对象无法保证与原文件逐像素一致；PDF 的文本读取顺序根据页面坐标推断。图片本身不导入。

本仓库没有附加开源许可证。
