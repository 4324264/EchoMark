# EchoMark 更新说明

## v0.4.1 — 2026-10-15

- 只保留浏览器识别，删除本机模型方案、加载入口、模型 Worker、采样工作线程及相关说明和缓存依赖。
- 移除模型可用性探测等待；持续监听、静音恢复、失败退避、会话隔离和近音匹配逻辑保留。
- 英语推荐指令采用 go to、skip、back，提示缩短为 go to start / skip 20 / back 20，兼容原有长指令。
- Material You 优化语义色彩层级、正文与设置区域比例、卡片状态、字体和触控间距。
- MiuiX 优化分组卡片、圆角、选中指示、细节间距、字体和按压反馈。
- 两套主题共用尺寸与字号规则，以原版为基准，减少切换时页面元素大小变化。
- EchoMark 原版基础样式保持一致。识别不可用时可复制网页地址到系统浏览器打开。
- 给核心脚本与主题样式添加版本参数，防止更新页面混用旧缓存资源。

识别依赖浏览器服务。不支持语音服务的内嵌浏览器仍可手动标记，也可改用支持的系统浏览器。历史版本独立保留。
