# EchoMark v0.4.1

网页跟读标记工具。直接部署本目录，或在本目录运行静态服务器后访问。

- 语音仅使用浏览器 Web Speech 服务。静音自动恢复、失败退避、近音匹配与手动停止逻辑沿用上一版本。
- 英语简短指令：go to start、skip 20、back 20；原有长指令继续支持。
- 默认原版样式保持不变，Material You 和 MiuiX 优化视觉层级与操作状态。
- 阅读外观提供半覆盖、全覆盖、下划线标记。

[发行说明](CHANGELOG.md) · [界面设计依据](DESIGN.md) · [第三方组件与许可](THIRD_PARTY.md)

文档、进度与外观保存在当前浏览器。语音服务取决于浏览器、设备和网络，内嵌浏览器可能不支持。复杂文档版面和识别准确度不能保证完全还原。
