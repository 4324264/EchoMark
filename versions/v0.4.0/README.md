# EchoMark v0.4.0

网页跟读标记工具。直接部署本目录，或在本目录运行静态服务器后访问。

- 默认原版；界面风格可切换 Material You、MiuiX。
- 阅读外观可选半覆盖、全覆盖、下划线标记。
- 内置语音服务失败时可重试或主动启用本机识别。首次本机模型下载需要联网。
- 支持自然朗读、附近近音匹配、中文与英文位置指令，及手动选择位置。

[发行说明](CHANGELOG.md) · [界面设计依据](DESIGN.md) · [第三方组件与许可](THIRD_PARTY.md)

文档、进度与外观保存在当前浏览器。内置语音服务的可用性由浏览器决定；本机模型在 Worker 中处理音频，速度受设备性能限制。复杂文档版面和识别准确度不能保证完全还原。
