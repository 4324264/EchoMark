# EchoMark

**抄写时自然读到哪儿，标记就跟到哪儿。**

EchoMark 是一款以浏览器为中心的阅读与抄写进度标记网页。它不要求逐字朗读：用户抄写时自然读出或小声念到的内容会推动标记；跳过的文字会结合附近的内容尝试匹配。安静抄写时标记保持不动。

## 功能

- 导入 TXT、Markdown、HTML、DOCX 与可提取文字的 PDF，也可以直接粘贴文本。
- 使用中文、英语、日语或韩语语音识别（需当前浏览器支持 Web Speech API）。
- 已读内容高亮、当前位置跟随语音移动，并显示阅读进度、字符数和预计时间。
- 根据文档名称和内容指纹在当前浏览器保存阅读位置；同一文档再次导入时可恢复进度。
- 自定义背景、标记和正文颜色；偏好设置保存在当前浏览器。
- 可安装为渐进式网页应用。网页资源会由 Service Worker 缓存，文档内容不上传至 EchoMark 服务器。

## 开始使用

使用支持 Service Worker、ES modules 和 Web Speech API 的现代浏览器，从 localhost 或 HTTPS 地址打开 `index.html`。语音识别需要安全来源和麦克风权限；点击“开始标记抄写”后才会启动。识别服务由浏览器或系统提供，支持情况会因浏览器、设备、地区及网络而异。权限预检只在首次开始时执行，并会立即释放临时音频流。

DOCX 解压使用浏览器内置的 `DecompressionStream`。PDF 导入按需从 jsDelivr 加载 Mozilla PDF.js 6.3.289，因此首次导入 PDF 需要网络；仅提取含有可选择文字的 PDF 内容，扫描件需先进行 OCR。复杂版式、表格和多栏页面的文本顺序可能与原文不同。

## 实现结构

- `index.html`：网页结构、导入与识别控件、阅读区域。
- `styles.css`：响应式布局、阅读界面和可定制主题。
- `app.js`：文件解析、规范化索引、语音匹配、进度恢复和界面状态。
- `sw.js`、`manifest.webmanifest`：离线网页资源缓存及安装信息。
- `icon.svg`：网页应用图标。

语音文字首先在当前位置后的有限窗口中匹配，再逐步扩大查找范围，最多到文档余下文本的 90%。精确片段使用原生字符串搜索；跳读场景使用增量半全局对齐，降低重复扫描。单字结果只在当前位置附近的小范围内接受，以减少误跳。临时语音结果经过短暂稳定等待，并避免和最终结果重复推进进度。

## 数据与限制

文档只在当前页面内存中处理，阅读进度和外观偏好保存在浏览器本地存储。清除浏览器站点数据会删除这些偏好和进度。当前版本没有账户或跨设备云同步。

语音识别质量取决于浏览器和环境；扫描版 PDF 不含可直接提取的文字，复杂 DOCX/PDF 排版不会完整保留。超大文档在构建文本索引时会占用更多内存。
